📖 About the Project

CineBook is a modern movie-ticket-booking web application that brings movie discovery, seat reservations, food ordering and AI-powered assistance together in one platform.

Users can explore movies, discover films based on their mood, select seats, apply offers, simulate payments and access their confirmed tickets.

⚙️ Run Locally

Prerequisites

- Node.js
- npm

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory

cd cinebook_project

3. Install dependencies

npm install

4. Configure the Gemini API key

Create a ".env.local" file in the project root.

Add your Gemini API key:

GEMINI_API_KEY=your_gemini_api_key

Use the environment variable names specified by the actual project configuration. Never upload your real API key to GitHub.

5. Run the application

npm run dev

Open the local URL displayed in your terminal.
